Starlight Infiltration is an original top-down 2D stealth game set in a dark star-vault facility. Infiltrate the high-security installation, evade patrolling guards with line-of-sight vision cones, collect the rotating Star Core and optional golden data shards, and escape through the green exit gate.

## Run it

```sh
node main.ts
```
